【理想張り索モデルからの加速度上界：ユーザー要望の式】
推定質量 mL = その周期のEKF mL、機体質量 mD、索長 L、重力 g、

既存HLCの飽和を外部から確認できた 0<=f<=Fmax を仮定すると、
  aD = -g e3 + (f/mD)b + (T/mD)q
  aL = -g e3 - (T/mL)q
  T = (mD*mL/(mD+mL))*L*||qdot||² - (mL/(mD+mL))*f*(qᵀb)
  omega = q×qdot, domega/dt = -(f/(mD*L))*(q×b)
ゆえに、|omega(t)| <= |omega(0)| + Fmax*t/(mD L) = Omega(t) なら
  |T(t)| <= (mD*mL/(mD+mL))*L*Omega(t)²+(mL/(mD+mL))*Fmax = Tmax(t)
  |aD(t)| <= g + Fmax/mD + Tmax(t)/mD

【予測誤差チューブの定義：さらに必要な外部証明】
現在モデル予測中心を pbar とし、もし
  ||p(0)-pbar(0)||<=rho_p0, ||v(0)-vbar(0)||<=rho_v0,
  ||a(t)-abar(t)||<=DeltaA_k  for all t∈[t_k,t_{k+1}]
の真の差上界が得られたとき、
  rho_v[k+1] = rho_v[k] + DeltaA_k*h_k,

## 1. 当時何を検討していたか（会話抜粋から確認できる範囲）

**吊り荷付きドローンの障害物回避に関連する未来予測**の方針を検討していた。特に、公称・目標軌道に正確に乗っていない現在状態から、軌道への合流中の動きをどう予測して衝突の可能性を評価するかが焦点だった。

ユーザーが問題視していたのは、従来の予測が経路から逸脱した状態を扱えるのかという点と、「未来も同じ入力が続く」といった根拠のない仮定による予測である。関連する先行研究を確認して、軌道上にいる前提なのか、逸脱状態に対応する方法があるのか調べることを求めていた。
