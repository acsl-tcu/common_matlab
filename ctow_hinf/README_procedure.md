## 1. 前提と記号

### 1.1 対象のシステム（x 軸、1 機分）

$$x = [p,\ p',\ p'',\ p^{(3)},\ p^{(4)},\ p^{(5)}]^\top,\quad p^{(6)} = v,\quad p'' = r\,x_3 + w$$

- **x₃：** ケーブルの水平力 ÷ 想定した担当質量。振れ角は θ ≈ x₃ / g。
- **r：** 想定した担当質量 ÷ 実際に効く有効質量（質量比）。単機で質量が正しければ r = 1。協調搬送では剛体モードごとに異なる（例：棒を両端で持つときのヨーで 3、正方形フレームのヨーで 1.5）。
- **w：** 吊り点の外力 ÷ 想定質量。単機では風や模型誤差、協調搬送では他の機体から牽引物を介して伝わる相互作用力。

`[A,B,E] = ctow_chain(r)` で、ẋ = A(r)x + Bv + Ew が得られる。

### 1.2 実装の条件

| 項目 | 値 |
|---|---|
| 制御周期 | 25 ms（`P.dt`） |
| 状態 | EKF と解析変換で x₁〜x₆ はすべて既知 |
| 実行 | v を 1 回計算し、一定として積分して角速度指令 c を作る |
| むだ時間 | 1 サンプル |
| FC | 角速度指令を一次遅れ τ_r で追従（10・30・50 ms で評価。`P.tau_list`） |

### 1.3 これまでの検討で分かっていること

1. **連続時間で設計したゲインは、25 ms 周期で不安定になることがある。** 現行の LQR（G0）は実装モデルで単機でも不安定（ρ ≈ 2.4）と予測される。設計した制御器は、必ず `ctow_impl_rho` で ρ < 1 を確認する。実現できる速い極は約 10 rad/s 以下。
2. **比較の基準は G1（LQR、R = 1e-2）。** 主要な極は現行と同じで、実装モデルで安定。
3. **H∞ で r へのロバスト性を強く求めると遅くなる。** 性能の重みの調整が重要。
4. **事前検討の結果（Python）：標準的な重みの H∞ は、協調搬送の構造モードの指標 ζ_min を改善しない。**

   | 設計 | 速さ σ | r 保証（‖T_Δ‖∞） | ζ_min |
   |---|---|---|---|
   | G1（LQR） | 0.37 | 保証なし | 3.5% |
   | G2（最適化した静的ゲイン） | 0.37 | 保証なし（実際には r ≲ 4.4 で安定） | 0.96% |
   | 設計 A の初期値（`run_stage3_designA`） | 約 0.34 | 0.86（保証あり） | 約 4.4% |

   標準的な H∞ の評価出力（位置・振れ角・操作量・r の不確かさ）は、構造との結合を直接扱っていないためである。単機の段階での H∞ の売りは「r に対するロバスト安定の保証」と「外乱応答の改善」にあり、ζ_min は「協調搬送に進むには構造との結合を一般化プラントに入れる必要がある」ことを示す指標として記録する（7 章）。

## 2. 段階 2：一般化プラント（協調搬送を見越した設定）

`G = ctow_genplant_A(P, opt)` が作る一般化プラントは次のとおり。

### 2.1 外生入力（外乱チャネル）：どちらも p'' の段（E）から入る

| 入力 | 単機での意味 | 協調搬送での意味 |
|---|---|---|
| w_int（重み b_int） | 吊り点の外力 | 他の機体からの相互作用力 |
| w_Δ | 質量比 r の不確かさの入口 | 剛体モードごとの r のずれ |

協調搬送では、相互作用力も質量比の誤差も「吊り点の加速度の段に入る外力」として現れる。同じ入口を使っておけば、2 セット結合や 4 台フレームのモデルにつなぐとき、一般化プラントを作り直す必要がない。

### 2.2 不確かさ（質量比 r）

r = r₀(1 + W_r δ)、|δ| ≤ 1、r ∈ [0.5, 3.5] → r₀ = 2、W_r = 0.75（`P.r0`、`P.Wr`）。

z_Δ = r₀ W_r x₃、w_Δ = δ z_Δ。小ゲイン定理により、**‖T_{w_Δ→z_Δ}‖∞ < 1（`ctow_eval` の `TD_inf`）なら、この範囲の r で安定が保証される。**

注意：一般化プラント全体の γ < 1 を要求すると、性能のチャネルも含めた条件になり、厳しすぎる。ロバスト性は `TD_inf` で別に判定する。

### 2.3 評価出力

| 出力 | 中身 | 協調搬送での意味 |
|---|---|---|
| z_perf | α · diag(√Q_shape) · x（Q_shape は LQR の Q と同じ形） | 搬送の性能（位置とその微分） |
| z_θ | q_θ · x₃ / g | 振れ角の振動の抑制。セット間の相互振動や内力のモードは振れ角に現れる |
| z_Δ | r₀ W_r x₃ | 剛体モードごとの r のずれへのロバスト性 |
| z_v | ρ_v · v | 操作量の抑制。速い極を抑える |

`opt` の既定値（α = 0.01、q_θ = 0、b_int = 0.3、ρ_v = 0.003）は、事前検討で「r 保証あり・実装モデルで安定・σ ≈ 0.34」となった値である。

## 4. 段階 3：設計 A（静的な重み、連続時間の状態フィードバック H∞）

```matlab
run_stage3_designA
```

処理の流れは次のとおり。

1. `ctow_genplant_A` で一般化プラントを作る。
2. `ctow_hinf_gamma_opt` で γ_opt を求める。
3. γ = min(1, 1.5γ_opt) で解く。v = −Kx。
4. `ctow_eval` で評価する。
5. 判定を表示する。
6. G1・G2 と時間応答（S1：位置のステップ、S2：外力のステップ）を比べる。

**期待される結果（Python で事前確認した値）：** γ_opt ≈ 0.894、γ = 1、K ≈ [125.8, 779.3, 1414.1, 559.4, 124.5, 16.3]、σ ≈ 0.335、‖T_Δ‖∞ ≈ 0.86、ζ_min ≈ 4.4%。これと大きく違う場合は、コードを確認すること。

### 重みの調整の方向

| したいこと | 調整 |
|---|---|
| 速くする | α を上げる。ただし ‖T_Δ‖∞ が 1 に近づく |
| r 保証を強くする | α を下げる、または r の範囲を狭める |
| 速い極を下げる（実装モデルが不安定なとき） | ρ_v を上げる |
| 振れ角を抑える | q_θ を上げる（0.3〜3 を試す） |

### 判定と次のアクション（スクリプトが表示する）

- **OK（‖T_Δ‖∞ < 1、σ ≥ 0.3、τ_r = 10〜50 ms で ρ < 1）：** 段階 4・6 に進む。
- **実装モデルで不安定：** ρ_v を上げる、または γ を大きくする。直らなければ段階 5 へ。
- **r 保証と速さが両立しない：** α を 0.003〜0.03、r の範囲を [0.7, 3] などに振って (σ, ‖T_Δ‖∞) のトレードオフ図を作り、PI に相談する。

## 5. 段階 4：設計 B（周波数重み付き H∞）

指針は次のとおり（コードは学生が作る）。

1. **重み W_θ(s) を加える：** x₃ / g を入力とする 2 次のバンドパス（1〜6 rad/s、中心 2〜3 rad/s）。状態を x に加えた拡張状態 x_a = [x; x_W] で、A_a、B1_a、B2_a、C1_a を作る。
2. **定常偏差をなくしたい場合：** 積分器 ξ = ∫p を状態に加えて、ξ に重みを付ける。純粋な積分器を重み関数側に置くと、虚軸上の極になって解けない。
3. **解く：** `ctow_hinf_sf(A_a, B1_a, B2_a, C1_a, rho_v, gamma)` でそのまま解ける（拡張状態はすべて制御器が計算できるので、状態フィードバックの形でよい）。
4. **実装モデルで評価する：** 重みのフィルタは制御器の中で周期 dt ごとに離散化して回す。制御器（入力 [x; c]、内部状態 x_W、出力 v）を `ss(..., P.dt)` で作り、`ctow_impl_rho_dyn` で ρ を評価する。

### 判定と次のアクション

- **OK：** 設計 A の条件を満たし、‖T_{w→θ}‖∞（`Twth_inf`）と S2 の振れ角の最大値が設計 A より小さい。段階 5 に進む。
- **改善しない：** W_θ の帯域と大きさを振った結果を報告する。

## 6. 段階 5：設計 C（実装の周期と遅れを含めた離散時間 H∞）

連続時間の設計は、25 ms の周期と遅れを設計に入れられない。最終的な設計は、実装と同じ離散時間モデルの上で行う。

```matlab
P  = ctow_params();
Pg = ctow_genplant_impl(P);                 % 離散時間の一般化プラント（状態 [x; c]）
[Kd, CL, gam] = hinfsyn(Pg, 7, 1);          % 計測 7（[x; c]）、制御 1（v）
rho = arrayfun(@(t) ctow_impl_rho_dyn(Kd, P, t), P.tau_list)
```

- 計測に小さなノイズ（eps = 1e-3）を入れているのは、`hinfsyn` の正則性条件（D₂₁ がフル行ランク）を満たすため。
- 得られる Kd は 7 次の動的制御器になる。
- 構造を固定した制御器（[x; c] に対する静的ゲイン）にしたい場合は、`tunableGain` と `hinfstruct` を使う。
- `ctow_genplant_impl` は雛形で、MATLAB では未実行。次元が合わないなどのエラーが出たら、コメントの入出力の定義に沿って直すこと。

### 判定と次のアクション

- **OK：** 設計 A の条件を満たし、実装モデルの ρ が設計 A 以下。段階 6 に進む。
- **NG：** 重みを設計 A の値に戻して解けるかを確認し、どの重みが効いているかを切り分けて報告する。

## 8. 段階 7：協調搬送への橋渡し

- **`minReGv`：** 外力から吊り点の速度までの局所ループの伝達関数の実部の最小値。0 以上なら受動的で、負が小さいほど構造にエネルギーを注入しにくい。参考値は G1 が −0.026、G2 が −0.0055。
- **`zeta_min`：** 2 セット弾性結合で、全ての構造共振周波数に対して安定になるのに必要な構造減衰比。参考値は G1 が 3.5%、G2 が 0.96%。動的な制御器（設計 B・C）の場合は、`ctow_two_set_rho` を制御器の状態を含む形に拡張する必要がある。
- **次の段階（今回の範囲外）：** ζ_min を下げるには、構造との結合を一般化プラントに入れる必要がある。候補は次の 2 つ。
  - 相互作用ポート（w → p'）の受動性の制約（散乱表現で H∞ ノルムの条件に書き換えられる）
  - 2 セット結合の相対モードを含めた一般化プラント

  2 章の外乱チャネルと評価出力は、そのまま使える。
