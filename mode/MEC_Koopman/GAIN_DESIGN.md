# MEC誤差ゲインの同定と検証

以前のゲインは、回帰行列の条件数が約 (1.5\times10^6) と大きく、25個の誤差観測量のうち5方向は標準化後の特異値が最大値の (10^{-3}) 未満でした。微小な数値誤差まで独立した状態として扱うと、同定係数とフィードバックゲインが大きくなり、誤差が少し増えたときにMEC入力が急増します。また、無単位の単位行列を使った状態・入力コストは、位置・姿勢・推力・トルクの大きさの違いを反映しません。

新しい手順では、試行単位で学習・調整・最終評価に分け、状態と入力をスケーリングしてからSVDで同定します。弱い状態方向を落とし、複数のridge係数から未学習試行の1ステップ誤差と20ステップ予測誤差がともに小さく、推定モデルが安定なものを選びます。LQRは12個の物理誤差に対する許容値と、4入力の物理スケールに合わせて設計します。

## 実行方法

リポジトリのルートで実行します。

```matlab
addpath(genpath(pwd));
[gain_file, model_file, report] = train_mec_gain();
```

入力データは `mode/MEC_Koopman/mec_gain_settings.m` の `dataset_dir` で指定します。既定値では `datasets/MEC_4input` を優先し、そこが空なら `datasets` の新形式ログを読み込みます。設定を変えて試行数が少なくなる場合は、異なる試行が少なくとも5つ必要です。

候補ゲインは、通常軌道、慣性差と外力を加えた軌道、未学習シード11・12のランダム軌道で、補償ON/OFFを比較します。全条件を完走し、位置RMSEが補償OFFに比べ25%を超えて悪化しなかった場合だけ既定ゲインにします。再学習の際も、この確認を自動で行います。

合格したゲインは `Data/MEC_design/mec_gain_regularized.mat` と `controller/mec_gain_regularized.m` に保存され、`MECKC` が読み込みます。MATファイルがGitの除外設定により共有されない場合も、係数を記したMATLABソースを読み込みます。前のゲインは `kalman_gainたち/ai_data_spline_KL_err_gain_controllable_dlqr_20261016_174715_924.mat` に残してあります。

`main_ERROR_KoopmanLinearByData_tutorial.m` は、新しい収集データから同定・設計・非線形検証まで実行する入口です。`Remake_kalman_ERROR_decoupling.m` は保存済みの正則化済みモデルからゲインだけを再計算します。元の対話式KL/LYKLとカルマン分解の処理は、それぞれのスクリプト末尾のブロックコメント内に残しています。

## 今回の結果

既定の10試行から25方向を20方向に圧縮し、正則化係数0.1を選びました。調整に使っていない試行の1ステップRMSEは (2.97\times10^{-4})、20ステップ正規化RMSEは0.713でした。LQR設計モデルの最大固有値絶対値は0.952です。

新ゲインを使った`mainGUI`は59秒まで完走しました。さらに、上記の4条件で補償ON/OFFを比べたところ、すべて59秒まで完走し、補償ONの位置RMSEは各条件で補償OFFとほぼ同じでした。これは今回のシミュレーション条件での確認であり、実機や別のモデル誤差に対する安定性を保証するものではありません。
