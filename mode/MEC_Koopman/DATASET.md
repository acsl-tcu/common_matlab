# MEC用データセットの収集

GUIの手動操作、外力・励振・補償の切替は [操作用README](README.md) を参照してください。

リポジトリのルートで、次を実行します。

```matlab
addpath(genpath(pwd));
files = collect_mec_dataset(1:10);
```

シードごとに40秒のランダムスプライン軌道を生成し、HLCの入力へ独立した
推力・roll/pitch/yawトルクの励振を加えます。位相と周波数もシードで変わります。
初期学習では既存MECゲインを使いません。世界座標の鉛直外力と慣性のモデル誤差は
`SimMEC_K.m` の設定を使用します。

```matlab
files = collect_mec_dataset([11,12,13], ...
    'amplitude',[0.5;0.008;0.008;0.006]);
```

振幅の順番と単位は `[推力 N; roll N m; pitch N m; yaw N m]` です。
各軸の励振絶対値は指定振幅以下で、離陸・着陸中は0です。
`mainGUI.m` から使う場合は `Setting.mec_dataset.enabled = true` とします。
シード一覧や周波数範囲などの標準値は `mec_dataset_settings.m` にあります。

## 同定する誤差系

`main_ERROR_KoopmanLinearByData_tutorial.m` と同じく、次を同定します。

```text
e[k+1] ≈ A e[k] + B dU[k]
dU[k] = u_plant[k] - u_nominal[k] = MEC補償[k] + 励振[k]
e[k] = Ψ(x_nominal[k]) - Ψ(x_estimated[k])
```

ノミナル状態は、前回の推定状態を前回のノミナル入力で1ステップ予測したものです。
独立したノミナル機体の軌道を積分し続ける構成ではありません。
同定対象は26観測量の誤差で、機体の12状態そのものではありません。

従来は予測状態と入力のログ番号がずれ、予測にも実機側の総入力を使っていました。
今回の修正で時刻と入力の定義をそろえています。旧データと新データは混ぜず、
新しい補償ゲインは今回のデータから再設計してください。

## 保存内容

通常ログは `Data/Sim_data`、学習用ファイルは `datasets/MEC_4input/MEC_seed_*.mat` に保存します。
学習用ファイルの `Dataset` は、次を含みます。

- `E`：26行N列、`dU`：4行N列、`E_next`：26行N列。
- 両側の入力、MEC補償量、励振量、元の時刻・ログ番号。
- 軌道シードと参照値、励振の位相・周波数、物理パラメータ、外力条件。
- 4入力と回帰行列のランク、各入力のRMS。

飛行中の連続した組だけを書き出し、初期化・時刻の飛び・段階切替を除外します。
自動試行で発散と判定して中断した試行は、学習用ファイルへ書き出しません。
学習・検証の両Importerは、このファイルを直接読み込めます。
GUIの手動実行でも、収集モードなら **Save data** から通常ログと学習用データを保存します。
同定スクリプトは、新しい専用フォルダにデータがあればそちらを優先します。
学習用と検証用ではシードを分けて収集してください。
