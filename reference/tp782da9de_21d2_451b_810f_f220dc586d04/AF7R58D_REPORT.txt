[B. P1 - EXACT SEGMENT COUNT, CONDITIONAL ON SUCCESSFUL CONSTRUCTION]
Production build_candidate uses C>=1 components, one start segment, C affine segments,

[C. P2 - COMMON FLOATING-POINT TREE, WITHOUT AN EXACT-REAL LOG2 SUBSTITUTION]
Fix the ACTUAL t0, searchEnd, dt, tolMerge and arithmetic environment for one call.
Define F(a,b) using exactly the scalar arithmetic in build_episode:
  tc=0.5*(a+b); splittable=finite(tc) && a<tc && tc<b;
  terminal iff computed(b-a)<=computed(dt+tolMerge) OR !splittable;
  N_F(a,b)=1 for a terminal node, otherwise N_F(a,tc)+N_F(tc,b).
Ignore geometry-only early safe exits when defining this full tree.
Every valid split has strictly interior endpoints. Finite binary64 has finitely many
representable values in a finite interval, so this conceptual tree is finite.
This argument is NOT a practical time bound and does not enumerate that tree.
For one call the tree is common to all obstacles because splitting and stopping use
the same time endpoints and dt. Every emitted unsafe leaf is a terminal cell of F.
A safe early-exit node contributes no unsafe cells. Each obstacle selects a subset
of the same ordered N_F cells. Merging adds cells between existing cell endpoints.
The all-obstacle union is therefore still a subset of these ordered cells.

  N_F >= C+(C-1) => C <= floor((N_F+1)/2) = ceil(N_F/2).

[D. P3 - LIVE GROUP PACKING: CONDITIONAL THEOREM, NOT CURRENT ENFORCEMENT]

[E. P4 - MULTI-OBSTACLE COMPUTATION IS NOT BOUNDED BY C ALONE]

[F. P5 - INDIRECT CABLE-MOTION BOUND UNDER THE TAUT-CABLE FLATNESS MODEL]

that relation. Do not silently apply it outside the stated model.
