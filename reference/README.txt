AF7R35A — separator eigenspace forensic
========================================

The prior C34 result proved that the native candidate does NOT satisfy either
physical halfspace generated by the MATLAB separator n=[0,1,0]. Therefore
stored sign labels are not the issue.

This audit distinguishes the two remaining possibilities:

1) VALID_DEGENERATE_TOP_EIGENSPACE__NONCANONICAL_BASIS_CHOICE
   MATLAB and C++ selected different vectors from the same repeated principal
   eigenspace. Both solve the same set-valued separator optimization, but the
   normal rule is not cross-platform canonical.

2) CPP_JACOBI_NOT_PRINCIPAL__IMPLEMENTATION_BUG
   The R14 C++ Jacobi eigensolver produced a direction that is not actually a
   principal eigendirection of the projected ellipsoid metric.

It exactly ports the AF7R34 C++ Jacobi update order into MATLAB, then:
- compares its direction to MATLAB eig(),
- checks eigen residual / Rayleigh optimality / progress orthogonality,
- constructs MATLAB corridor rows using the C++-ported direction,
- checks whether the native candidate satisfies that physical corridor.
