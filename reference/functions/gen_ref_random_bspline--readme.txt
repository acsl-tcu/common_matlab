================================================================================
 gen_ref_random_bspline.m  解説
 （進行方向へのyaw追従に対応したランダム目標軌道の生成）
================================================================================

--------------------------------------------------------------------------------
1. 概要
--------------------------------------------------------------------------------
NN-MEC などの学習データを集めるための，ランダムな目標軌道を生成する．
TIME_VARYING_REFERENCE にそのまま渡せる形式で，位置と yaw 角の 0～4 階微分を返す．

使い方（第3引数の order は付けない．微分は内部で解析的に計算している）:

    ref = TIME_VARYING_REFERENCE(agent,{"gen_ref_random_bspline",{"T",60,"yaw_follow",1,"seed",1}});

指定しなかった引数は既定値になる（既定値は「3. 設定変数」を参照）．

--------------------------------------------------------------------------------
2. 生成のしくみと設計意図
--------------------------------------------------------------------------------
(1) 制御点をランダムウォークで作る
    knot_dt ごとに「速さ v」と「進行方向 theta」を少しずつランダムに変えながら
    1 歩ずつ進み，その点を B スプラインの制御点にする．
      - 1 歩の長さ   : v * knot_dt
      - 1 歩の旋回角 : -turn_max ～ +turn_max
    範囲の端に近づくと中心方向へ曲げ，範囲の外に出る歩は採用しない．

(2) 一様 B スプラインで滑らかにつなぐ（次数 degree）
    - 凸包性：軌道は制御点の凸包の中に収まる．制御点がすべて範囲内なら，
      軌道全体も必ず範囲内になる（waypoint 間で範囲外にはみ出さない）．
    - degree 次の B スプラインは (degree-1) 階微分まで連続．HL 制御器は
      4 階微分まで使うので degree >= 5，yaw_follow では位置の 5 階微分まで
      使うので degree >= 6 が必要．

(3) 始点・終点は静止
    始点と終点の制御点を重ねることで，t = 0 と t = T で速度～4 階微分が 0 になる．
    離陸後のホバリングから滑らかに始まり，最後はホバリングに戻る．
    t > T では終点で静止し続ける（周期的に繰り返さない）．

(4) 始点直後・終点直前は直線で加減速
    速度 0 の瞬間は進行方向が定まらないため，加速区間と減速区間は直線にしている．
    この間の yaw 角は一定（加速区間は start_yaw，減速区間は最後の進行方向）．

(5) yaw 角を進行方向へ向ける（yaw_follow = 1）
    旋回角を制限しているので途中で速度が 0 にならず，進行方向 atan2(vy, vx) が
    常に定まる．yaw 角とその 1～4 階微分は速度から解析的に計算するので，
    進行方向との誤差はほぼ 0（数値誤差 1e-13 rad 程度）．
    yaw 角は ±π で折り返さない連続値（例：-30 rad もありうる）．
    制御器（FUNCTIONAL_HLC_SERVO）は目標 yaw 角で回転した座標系で計算し，
    EKF は観測残差だけを ±π に折り返すので，連続値のままで問題ない．

(6) 検証して作り直す
    生成した軌道について，傾き角・yaw 角速度・各軸の利用幅を検証し，
    満たさなければ作り直す（最大 max_attempts 回）．
    見つからなかった場合は，棄却理由の内訳と見直す設定をエラーメッセージに表示する．

--------------------------------------------------------------------------------
3. 設定変数（既定値は 2026/10/23 時点のファイルの値）
--------------------------------------------------------------------------------

■ 時間・空間

  T = 60  [s]
    飛行時間．knot_dt の整数倍に丸める．
    加速区間（約 3 s）と，終盤の減速・中心への復帰（約 9 s）の間は自由に
    動けないので，ランダムに動き回れるのはおおよそ T - 12 s．
    T を短くするときは coverage も下げること（T = 20 で coverage = 0.7 はほぼ不可能）．
    最短は 3*degree*knot_dt（既定値で 9 s）．

  start = [0;0;1]  [m]
    始点．離陸後のホバリング位置に合わせる．範囲内でなければエラー．
    範囲の端に近いと，加速区間の直線が範囲外に出て失敗しやすい．

  start_yaw = 0  [rad]
    始点での yaw 角であり，加速区間の進行方向でもある．離陸時の yaw 角に合わせる．
    yaw_follow = 0 のときは飛行中ずっとこの値で一定．

  xlim = [-1.5 1.5], ylim = [-1.5 1.5], zlim = [0.5 1.5]  [m]
    飛行範囲．軌道全体がこの直方体に必ず収まる（凸包性）．
    実験場の安全な範囲を指定する．

■ 速度・旋回

  speed = [0.1 1]  [m/s]
    水平速度の大きさ（速さ）の範囲 [min max]．向きは含まない．
    向きは旋回で 0～2π のあらゆる方向を取るので，vx, vy は正にも負にもなる．
    min > 0 が必要（速さ 0 では進行方向が定まらない）．
    ときどき（各歩 25% の確率で）目標速度を範囲内から一様に選び直し，
    加減速を制限しながら近づけるので，範囲内のいろいろな速さが現れる．
    B スプラインで滑らかにするため，実際の速さは範囲を少しはみ出す．
    上限は範囲の広さとの兼ね合いで決める（下の「旋回半径」を参照）．

  vz_max = 1  [m/s]
    鉛直速度の上限．z 方向は水平とは別に，-vz_max ～ +vz_max の符号付きで
    ランダムに変化する（上昇も下降もする）．
    1 歩の上下移動 vz_max*knot_dt が z の範囲幅より十分小さくないと，
    範囲外に出て失敗する（以前 vz_max = 5 では 1 歩 2.5 m で失敗した）．

  turn_max = pi/4  [rad]
    制御点 1 つ（knot_dt）あたりの最大旋回角．
    旋回の速さ（≒ yaw 角速度）の目安は turn_max/knot_dt．
    理論上，(degree-1)*turn_max < pi のとき「途中で速度が 0 にならない」こと，
    および yaw 角の分枝の選び方が正しいことが保証される（degree = 6 なら
    turn_max < pi/5）．pi/4 はこの条件を満たさない．
    2026/10/23 に 20 シードで確認した範囲では，pi/4 でも yaw 角の跳びは無く，
    中間区間の最小水平速度も約 0.09 m/s だったが，保証はされない．
    yaw の 4 階微分も大きくなる（pi/8 で約 70，pi/4 で約 180 rad/s^4）．

  knot_dt = 0.5  [s]
    制御点の時間間隔．小さいほど細かい動き（高い周波数）になり，加速度や
    yaw 角速度が大きくなる．大きいほどゆったりした軌道になる．

  ※ 設定値どうしの関係（目安）
      1 歩の水平移動     : speed * knot_dt
      旋回半径           : speed * knot_dt / turn_max
                           → 範囲の半幅（既定 1.5 m）より十分小さくないと，
                             端で曲がり切れずに失敗する
                             （以前 speed 上限 5 m/s では半径約 6.4 m で失敗した）．
      旋回の速さ         : turn_max / knot_dt  [rad/s]
      旋回による加速度   : speed * turn_max / knot_dt  [m/s^2]
                           → tilt（傾き角）に効く

■ 滑らかさ

  degree = 6
    B スプラインの次数．(degree-1) 階微分まで連続．
    yaw_follow = 1 のときは 6 以上が必要（yaw の 4 階微分に位置の 5 階微分を使うため）．
    次数を上げると滑らかになるが，制御点の影響が広がり，turn_max の条件
    （(degree-1)*turn_max < pi）が厳しくなる．

■ yaw 角

  yaw_follow = 0
    1: yaw 角を進行方向（水平速度の向き）に向ける．
    0: yaw 角を start_yaw で一定にする．

  max_yaw_rate = pi  [rad/s]
    yaw 角速度の上限（yaw_follow = 1 のときだけ検証）．超える軌道は作り直す．
    旋回の速さの目安 turn_max/knot_dt と同程度に設定すると，B スプラインの
    平滑化で瞬間的に少し超えるため，ほとんどの軌道が棄却される
    （以前 turn_max = pi/8, knot_dt = 0.5 で max_yaw_rate = pi/4 にして失敗した）．
    目安の 1.3～1.5 倍以上にしておくとよい．

  yaw_wind_max = 2*pi  [rad]
    yaw 角の累積回転量 |yaw - start_yaw| の上限の目安（yaw_follow = 1 のときだけ有効）．
    範囲内で壁を避けるうちに同じ向きに回り続け，yaw 角が一方向に増え続ける
    ことがある（制限なしでは 60 s で ±30 rad，回転方向の 9 割以上が同じ向き）．
    上限を超えたら，始点の yaw 角付近（±pi/2）に戻るまで逆回りに旋回させる．
    逆回りの半周旋回が範囲内に収まるように，必要なら減速する．
    これにより回転方向がほぼ半々になり，学習データの偏りを防げる．
    yaw 角は最大でおよそ ±9 rad まで振れる．inf にすると制限なし．

■ 検証

  max_tilt = pi/4  [rad]
    傾き角の上限．超える軌道は作り直す．
    傾き角 tilt は，目標の加速度 a を出すのに必要な機体の鉛直からの傾き：
        tilt = atan2(|a_xy|, g + a_z)
    roll と pitch を合わせた全体の傾きの大きさ（cos(tilt) = cos(roll)cos(pitch)）
    で，yaw の向きには依存しない．空気抵抗は無視している．
    旋回による加速度の目安 speed*turn_max/knot_dt から，既定値（speed 上限 1 m/s，
    turn_max = pi/4，knot_dt = 0.5 s）では tilt は 0.16 rad 程度で，上限よりかなり小さい．
    実際の値は生成時にコマンドウィンドウへ表示される「最大傾き」で確認できる．

  coverage = 0.7
    各軸の「利用幅」の下限．利用幅 = (軌道がその軸で動いた幅 max-min)/(範囲の幅)．
    x, y, z すべてが下限以上でないと作り直す．
    既定の範囲では，x, y 方向に 2.1 m 以上，z 方向に 0.7 m 以上動く必要がある．
      0      : チェックしない
      0.3～0.5: 範囲の一部に偏った軌道だけを除く
      0.7    : 範囲の大部分を使う軌道だけを残す
      1      : 全軸で両端に触れる必要があり，ほぼ不可能
    注意：両端の幅しか見ておらず，範囲をまんべんなく動いたかは評価しない．
    また位置の広がりしか見ておらず，速度・加速度・姿勢の多様さは評価しない．
    DNN12 の入力は状態の差 (x_plant - x_nominal) なので，学習への影響は
    位置の広がりより速度・姿勢の励起の方が大きいと考えられる．

■ その他

  seed = []
    乱数の seed．[] なら毎回異なる軌道になり，使った seed をコマンドウィンドウに表示する．
    整数を指定すると同じ軌道を再現できる（シミュレーションと実機で同じ軌道を
    使いたいときなど）．内部で専用の乱数ストリームを使うので，グローバルな rng には影響しない．

  max_attempts = 100
    作り直しの上限回数．条件が厳しいと見つからずにエラーになる．

  check = 1
    1 なら確認図（figure 103）を表示する．
      左      : 3 次元の軌道と 1 秒ごとの機首方向（赤矢印），始点（緑の星）
      右上    : x, y, z の時間変化
      右中    : 水平速度の大きさ（実線），鉛直速度（破線），傾き角 tilt（右軸）
      右下    : yaw 角と yaw 角速度（右軸）

--------------------------------------------------------------------------------
4. 戻り値（構造体 ref）
--------------------------------------------------------------------------------
  ref.pYaw(t) : [x;y;z;yaw; dx;dy;dz;dyaw; ...; 4階微分] の 20×1
                （HL 制御器が使う xd(1:20) と同じ並び）
  ref.q(t)    : [roll;pitch;yaw] の 0～4 階微分 15×1（roll = pitch = 0）
                TIME_VARYING_REFERENCE はこれを result.state.q に入れる．
  ref.order   : 4
  ref.info    : seed, T, knot_dt, degree, control_points, param,
                stats（検証結果：位置・速度・傾き角・yaw の時系列，最大値，利用幅など）

--------------------------------------------------------------------------------
5. 生成に失敗したとき
--------------------------------------------------------------------------------
エラーメッセージに棄却理由の内訳と見直す設定が表示される．
  z方向に範囲外           → vz_max を下げる
  水平方向に範囲外        → speed の上限を下げる / 範囲を広げる / max_attempts を増やす
  加減速区間の直線が範囲外 → speed の下限を下げる / start を範囲の中央寄りにする
  傾き角が上限超過        → speed の上限か turn_max を下げる / max_tilt を上げる
  yaw角速度が上限超過     → max_yaw_rate を上げる / turn_max を下げる
  利用幅が不足            → T を延ばす / coverage を下げる

--------------------------------------------------------------------------------
6. 励起を強めたいとき（NN 学習用）
--------------------------------------------------------------------------------
  - 姿勢（tilt）を大きくする    : speed の上限を上げる，turn_max を上げる，knot_dt を下げる
                                  （範囲内に収まるよう，旋回半径に注意）
  - 上下方向の励起を強める      : vz_max を上げる（vz_max*knot_dt < z の範囲幅）
  - yaw 方向の励起を加える      : yaw_follow = 1
  - いろいろな軌道を集める      : seed を変えて複数回生成する（seed は記録しておく）
